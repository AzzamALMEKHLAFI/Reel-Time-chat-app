# Real-Time Chat App

A real-time chat application project designed to allow users to communicate instantly through a simple and practical interface.

## Overview

This project focuses on building a chat system where messages can be sent and received in real time. It is a useful project for practicing web development, client-server communication, real-time events, and user interface design.

## Features

- Real-time messaging
- Simple chat interface
- User-to-user communication concept
- Practical web application structure
- Suitable for learning full-stack development basics

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Socket.IO

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/AzzamALMEKHLAFI/Reel-Time-chat-app.git
```

2. Open the project folder:

```bash
cd Reel-Time-chat-app
```

3. Install dependencies:

```bash
npm install
```

4. Start the application:

```bash
npm start
```

5. Open the app in your browser:

```text
http://localhost:3000
```
